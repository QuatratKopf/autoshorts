AutoShorts

A private tool that creates short animated explainer videos and publishes them to the owner's own YouTube and TikTok accounts.

How it works

  1. The owner picks a video category or topic in the AutoShorts desktop app (or the daily schedule picks one).
  2. AutoShorts writes a script, generates voice-over and images and renders a vertical video.
  3. The video is uploaded to the owner's own channel through the YouTube API Services (and to TikTok through the TikTok Content Posting API).
  4. The app shows views, likes and comments of the channel's own videos in a dashboard.

YouTube API Services AutoShorts uses YouTube API Services. By connecting YouTube you agree to the YouTube Terms of Service.
